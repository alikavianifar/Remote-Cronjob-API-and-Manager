🛡️ Security & Stability Features

SECURITY Spawn over Exec Eliminates shell injection risks by using child_process.spawn instead of exec, ensuring user input is treated as data, not code.
PRIVILEGE Limited Sudo Node.js process runs as a standard user, utilizing configured sudoers permissions only for the `crontab` command.
STABILITY Drift Detection Implements "Magic Comments" & Reconciliation Loops to keep the database state in sync with the actual Linux crontab file.
REAL-TIME SSE Logging Uses Server-Sent Events (SSE) for minimal latency log streaming from the server to the client dashboard.

🚀 Technical Highlights

  • Native Integration: Uses the OS's native crontab. If the Node.js API crashes, your scheduled jobs keep running.
  • Zero Migration: Drop-in solution for existing servers. No need to rewrite scripts or move to Docker containers.
  • Stateless-First: The filesystem (crontab) is the single source of truth, enriched by metadata.
